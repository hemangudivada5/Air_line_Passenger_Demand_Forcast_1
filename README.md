# Airline Passenger Demand Forecasting ✈️

## Project Overview

Airline Passenger Demand Forecasting is a Data Science project focused on analysing historical airline passenger data and forecasting future passenger demand using time-series analysis and forecasting techniques.

The objective is to understand patterns in passenger demand over time and explore how historical data can support demand planning and informed decision-making in the aviation industry.

This project was completed as part of my M.Sc. in Data Science and Artificial Intelligence at BITS Pilani.

## Business Problem

Forecasting passenger demand is important for airline planning and operational decision-making. Understanding historical demand patterns can help airlines make better-informed decisions related to capacity planning, resource allocation and future travel demand.

This project explores how historical passenger data can be used to understand trends and generate forecasts for future periods.

## Project Objectives

- Analyse historical airline passenger data to understand demand patterns.
- Perform data exploration and preprocessing where required.
- Identify trends and seasonal patterns in the time series.
- Apply appropriate time-series forecasting techniques.
- Evaluate forecast performance using the methods implemented in the project.
- Visualise historical observations and forecasting results.
- Understand the potential applications and limitations of passenger demand forecasting.
